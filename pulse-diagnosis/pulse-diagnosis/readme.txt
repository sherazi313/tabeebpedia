== Introduction ==
Pulse Diagnosis is a unique plugin that helps diagnose temperament and disease by analyzing pulse patterns through a series of questions. Designed specifically for herbal or traditional medicine practitioners, the plugin guides the user through questions related to pulse characteristics.

== Description ==
This plugin enables you to diagnose health conditions based on six questions, each covering different aspects of pulse diagnosis. The results are calculated based on user input and displayed at the end of the quiz. The plugin's design includes a responsive and user-friendly interface, all in the Urdu language for native users.

Features:
1. Pulse diagnosis through a six-question quiz.
2. Display results based on pulse types: عضلاتی, غدی, اعصابی.
3. Complete right-to-left (RTL) support for the Urdu language.
4. Beautiful, color-coded question boxes.
5. Easy integration via shortcode `[pulse_diagnosis]`.

How to Use:
1. Upload the plugin files to your server.
2. Activate the plugin in the WordPress dashboard.
3. Use the shortcode `[pulse_diagnosis]` to display the quiz on any page or post.
