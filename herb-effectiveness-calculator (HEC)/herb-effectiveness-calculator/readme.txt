# Herb Effectiveness Calculator (HEC)

**Plugin Name**: Herb Effectiveness Calculator (HEC)  
**Author**: S.A.Wahab  
**Author Website**: [www.Nuktaguidance.com](https://www.Nuktaguidance.com)  
**Plugin Website**: [www.tabeebpedia.com](https://www.tabeebpedia.com)  

## Description

This plugin allows users to select herbs from predefined categories and calculate their effectiveness based on weight. The effectiveness is calculated by assigning 70% of the value to the first part of the herb category and 30% to the second part.

## Features

- Select herbs from six predefined categories.
- Input the weight for each herb.
- Calculate total effectiveness percentages based on weight.
- Manage herb categories via the WordPress admin panel.

## Installation

1. Upload the plugin files to the `/wp-content/plugins/herb-effectiveness-calculator` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Use the shortcode `[herb_calculator]` to display the calculator on any page or post.
